# Class Mate

Quiero crear un sistema de gestión de notas, que sea un modelo amigable con la experiencia usuario, que sus colores sean institucionales y con las siguientes funcionalidades:

Que saque promedio final de notas, entre 1-7.
Que pueda agregar notas y también asignar porcentajes a estas.
Que reconozca a cada evaluador que este ingresando datos.
División por materia en nota asignada (ramos que cada evaluador tenga).
Indicar en colores los aprobados en verde y reprobados en rojo.
Que muestre la lista de alumnos por orden alfabético, con una ventana que este fija con las notas y con los promedios finales.
